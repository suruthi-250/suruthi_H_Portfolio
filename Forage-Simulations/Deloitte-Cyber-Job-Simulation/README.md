# Deloitte Cyber Job Simulation

## Overview

This project documents my completion of the Deloitte Australia Cyber Job Simulation
through Forage.

I completed this simulation as an early introduction to cybersecurity. At the time,
I was still beginning to understand cybersecurity concepts and did not have a clear
understanding of how the activities related to real-world security operations.

Revisiting the simulation now has helped me better understand the concepts involved,
particularly web activity analysis, suspicious user activity, and investigating the
possible source of a data breach.

## Simulation Details

- Platform: Forage
- Organization: Deloitte Australia
- Area: Cybersecurity
- Level: Introductory
- Duration: Approximately 30–60 minutes
- Format: Virtual Job Simulation

## What the Simulation Covered

The simulation focused on investigating a cybersecurity incident involving the
leak of private company information.

The main activities involved:

- Reviewing web activity logs
- Identifying suspicious user activity
- Looking for unusual request patterns
- Investigating activity related to a potential data breach
- Using timestamps and request information to identify relevant activity

## Skills and Concepts

Through the simulation, I was introduced to:

- Log analysis
- Web security fundamentals
- Computer networking concepts
- Basic incident investigation
- Identifying suspicious activity from logs

## Reflection

This simulation was one of my early exposures to cybersecurity. When I originally
completed it, I had limited knowledge of security operations and did not fully
understand the reasoning behind the investigation.

Revisiting the experience now, while building toward a SOC Analyst role, gives me
a better perspective on how security analysts use logs and activity patterns to
investigate incidents.

It also highlighted the importance of understanding the fundamentals before
moving into more advanced security monitoring and incident response work.
