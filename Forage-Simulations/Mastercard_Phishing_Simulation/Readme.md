# Mastercard — Cybersecurity Job Simulation

## Overview

Completed Mastercard's Cybersecurity Virtual Experience Program through Forage.

The simulation focused on the role of a Security Awareness team and introduced practical concepts related to phishing prevention and security awareness.

## Tasks Completed

### Task 1 — Design a Phishing Email Simulation

The simulation involved examining a fake email and developing a phishing email simulation designed to support security awareness.

### Task 2 — Interpret Phishing Simulation Results

The second task focused on interpreting phishing simulation results and using the findings to identify areas where additional security awareness training could reduce organizational risk.

## Skills

- Phishing Awareness
- Security Awareness
- Phishing Simulation
- Data Analysis
- Security Training
- Communication
- Problem Solving

## Connection to My Independent Work

Before completing this simulation, I had already explored phishing through independent email-security investigations.

Completing the Mastercard simulation provided additional perspective on phishing from a **security awareness and organizational risk** standpoint, complementing my technical analysis of suspicious emails.
